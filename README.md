# 🐾 Terminal Pet

Милый ASCII-зверёк, который живёт прямо в твоём терминале.
Он голодает, устаёт, радуется, грустит и **помнит тебя между запусками** —
состояние сохраняется в `~/.terminal_pet.json`.

## Установка

```bash
pip install -e .
```

## Использование

```bash
terminal-pet greet      # питомец поприветствует тебя
terminal-pet feed       # покормить (восстанавливает голод)
terminal-pet play       # поиграть (тратит энергию, поднимает счастье)
terminal-pet sleep      # уложить спать (восстанавливает энергию)
terminal-pet tick       # пройти один "тик" времени
terminal-pet status     # полюбоваться на текущее состояние
terminal-pet info       # статистика: возраст, сколько раз кормили
terminal-pet reset      # начать заново (внимание: стирает сохранение!)

# задать имя при рождении:
terminal-pet greet --name Кексик
```

Запусти `tick` несколько раз подряд — питомец начнёт грустить, если за ним
не ухаживать. Покорми вовремя, и он проживёт долгую счастливую жизнь в твоём
скроллбуфере. 💙

## Что под капотом

* **`terminal_pet/pet.py`** — логика жизни: голод, энергия, счастье, настроение,
  старение, смерть от запущенности (береги питомца!).
* **`terminal_pet/ascii.py`** — ASCII-мордочки и цветные полоски статусов.
* **`terminal_pet/cli.py`** — командная строка.
* **`tests/`** — pytest-тесты основной механики.

Никаких внешних зависимостей — только стандартная библиотека Python.
